# Task Manager

A backend web application built using Node.js, Express, and PostgreSQL to manage tasks.

## 🚀 Features
- Create, update, delete tasks
- Server-side rendering using EJS
- PostgreSQL database integration

## 🛠️ Tech Stack
- Node.js
- Express.js
- PostgreSQL
- EJS

## ⚙️ Setup
1. Clone repo
2. npm install
3. Add .env file
4. node index.js
